## 🧑‍💻 About me

Software engineering student at **École 42**, where every project is built from scratch, with no frameworks and no shortcuts.

I focus on **systems programming**: memory management, processes, sockets and signals in C and C++. I'm just as comfortable on the **infrastructure** side, working with containers, reverse proxies and service orchestration, and I build **web** interfaces with React and TypeScript.
